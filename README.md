# Luach — privacy policy

The privacy policy for **Luach**, an iOS Jewish calendar, zmanim and blessings
reference, served at
<https://dilyagu22.github.io/LuachPrivacy/>.

This repository contains that one page and nothing else. The app itself is
closed source.

The short version: the app collects nothing. No account, no analytics, no
advertising, no tracking, and no network requests at all — the calendar engine
and every text ship inside the app. If you allow location, the coordinate is
used on the device to compute zmanim and to point the compass toward Jerusalem,
and it is never transmitted.
